# 详细探针指南

## 📋 概述

已为完整流程添加了详细的探针，追踪每个环节的具体处理过程，不仅仅是统计信息，而是详细的处理细节。

## 🔍 详细探针列表

### 1. docx内容提取详细探针

**位置**: `test_docx_to_ppt_full_flow.py::extract_docx_content`

**追踪内容**:
- ✅ **每个段落的详细信息**:
  - 段落索引
  - 文本内容（前100字符预览）
  - 样式名称
  - 是否加粗
  - 字号大小
  - 文本长度
- ✅ **每个表格的详细信息**:
  - 表格索引
  - 行数、列数
  - 每行的单元格内容
  - 内容预览
- ✅ **结构分析**:
  - 总段落数、总表格数
  - 可能的标题段落数量
  - 可能的正文段落数量

**输出示例**:
```
📝 段落提取（共X个段落）:
   段落0:
     文本: 技术产品商业化-文档...
     样式: Normal
     加粗: False
     字号: 12pt
     长度: 50字符
```

### 2. 人类中心化分析详细探针

**位置**: `human_centered_analyzer.py`

**追踪内容**:
- ✅ **第1层：通读理解**:
  - 从每张幻灯片收集的文本块数量
  - 每张幻灯片的文本预览
  - 总文本长度
  - 识别出的核心主题
  - 识别出的价值主张（每个价值主张的详细内容）
  - 识别出的文档目的
- ✅ **第2层：板块拆分**:
  - 每张幻灯片的处理过程
  - 识别出的板块数量

**输出示例**:
```
--- [HumanCenteredAnalyzer]: 【详细探针】第1层：通读理解
   收集文本内容（从3张幻灯片）...
     幻灯片0: 收集到2个文本块
       文本预览: 技术产品商业化...
   总文本长度: 3303字符
   核心主题: 技术产品商业化
   价值主张数量: 3
     价值主张1: 降低运营成本40-60%
```

**位置**: `content_strategy_generator.py::_generate_section_strategies`

### 4. 内容生成详细探针

**位置**: `ppt_filler.py::_generate_content_by_sections`

**追踪内容**:
- ✅ **LLM调用前**:
  - 提示词长度
  - 提示词预览（前500字符）
- ✅ **LLM返回后**:
  - 返回数据类型
  - 标题内容
  - 内容长度
  - 关键点数量
  - 数据高亮数量
  - 案例数量
- ✅ **结构化后**:
  - 结构化后的标题
  - 主要内容长度
  - 关键点列表（前3个关键点的预览）

**输出示例**:
```
--- [PPTFiller]: 【详细探针】调用LLM生成板块1内容...
   提示词长度: 2500字符
   提示词预览: 【整体背景】核心主题：技术产品商业化...
--- [PPTFiller]: 【详细探针】LLM生成结果:
   标题: 技术产品商业化概述
   内容长度: 500字符
   关键点数量: 3
   数据高亮数量: 2
```

### 5. 内容映射到占位符详细探针

**位置**: `ppt_filler.py::_map_to_placeholders`

**追踪内容**:
- ✅ **映射前**:
  - 结构化内容的详细信息（标题、主要内容长度、关键点数量等）
  - 目标幻灯片列表
  - 框架PPT的幻灯片数
- ✅ **每个占位符的处理**:
  - 占位符ID
  - 占位符类型（TITLE/BODY/OBJECT等）
  - 占位符键名（slide_X_placeholder_Y）
  - 分配的内容类型（标题/正文）
  - 分配的内容预览（前100-150字符）

**输出示例**:
```
--- [PPTFiller]: 【详细探针】内容映射到PPT占位符
   结构化内容:
     标题: 技术产品商业化概述...
     主要内容长度: 500字符
     关键点数量: 3
   --- 处理幻灯片0 ---
     占位符数量: 2
     占位符0:
       类型: CENTER_TITLE
       键名: slide_0_placeholder_0
       → 分配标题内容: 技术产品商业化概述...
     占位符1:
       类型: BODY
       键名: slide_0_placeholder_1
       → 分配正文内容: 500字符
         内容预览: 全链路AI赋能解决方案，通过...
```

## 📊 如何使用

运行测试脚本时，所有详细探针信息会输出到：
1. **控制台**：实时显示
2. **日志文件**：保存到 `docx_to_ppt_test_YYYYMMDD_HHMMSS.log`

## 🎯 关键信息追踪

通过这些详细探针，你可以追踪：

1. **从文档读取了什么内容**：
   - 每个段落的具体内容、样式、格式
   - 每个表格的具体内容

2. **进行了怎么样的拆分**：
   - 人类中心化分析的6层分析结果
   - 每个板块的主题、核心思想
   - 每个板块分配的幻灯片

3. **对拆分的内容进行了怎么样的调整和润色**：
   - LLM的提示词（可以看到如何指导LLM生成）
   - LLM的返回结果（可以看到生成的内容质量）
   - 结构化后的内容（可以看到如何组织内容）

4. **在哪里放置了PPT占位符**：
   - 每个占位符的类型、位置（幻灯片索引、占位符ID）
   - 每个占位符分配的具体内容
   - 内容预览
