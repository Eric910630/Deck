## 📊 Ant Design实际设计原则

### 1. 布局原则
- **留白优先**：大量留白，内容不拥挤
- **卡片式布局**：使用Card组件包裹内容
- **网格系统**：基于24栅格系统

### 2. 视觉层次
- **通过阴影和边框**：而不是背景色
- **通过字号和字重**：而不是颜色
- **通过间距**：而不是装饰

### 3. 颜色使用
- **主色用于强调**：按钮、链接、重要信息
- **背景色用于区分**：页面背景（#f0f2f5），卡片背景（#ffffff）
- **文本色用于层次**：主文本、次文本、辅助文本

## 🔧 如何真正符合Ant Design规范

- 主色文字（#1890ff）
- 加粗
- 居中
- **不要**全宽背景条

```python
# 标题样式

```

- 白色背景（#ffffff）

- 阴影（轻微，如果支持）

**代码示例**：
```python
# Card样式
fill.solid()
```
