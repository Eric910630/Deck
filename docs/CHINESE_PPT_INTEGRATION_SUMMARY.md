## 🎨 设计特点

### 1. 颜色方案

**主色调**:
- 红色（#d32f2f）: 权威、正式
- 金色（#ffb300）: 喜庆、重要

**文本色**:
- 深灰（#212121）: 主文本，正式
- 中灰（#616161）: 次文本

**背景色**:
- 白色（#ffffff）: 基础背景
- 浅灰（#fafafa）: 容器背景

### 2. 字体方案

**标题字体**:
```css
font-family: 'Microsoft YaHei', 'SimHei', '黑体', sans-serif
```

**正文字体**:
```css
font-family: 'SimSun', '宋体', 'Microsoft YaHei', sans-serif
```

**强调字体**:
```css
font-family: 'KaiTi', '楷体', serif
```

### 3. 布局模式

**对称均衡布局**（两个内容块，内容长度相近）:
```
┌─────────────────────────────┐
│        主标题（红色，居中）    │
├──────────────┬──────────────┤
│  左侧内容     │  右侧内容     │
│  （对称）     │  （对称）     │
│              │              │
└──────────────┴──────────────┘
```

**主次分明布局**（两个内容块，内容长度差异大）:
```
┌─────────────────────────────┐
│        主标题（红色，居中）    │
├──────────────┬──────────────┤
│  主要内容     │  次要内容     │
│  （大）       │  （小）       │
│              │              │
└──────────────┴──────────────┘
```
