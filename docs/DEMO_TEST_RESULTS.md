```

  - 副标题: 探索AI技术的核心原理、发展历程与未来趋势
  - 占位符: 2个

幻灯片 2:
  - 标题: 人工智能核心技术介绍
  - 内容: 包含5个核心技术点
  - 占位符: 2个

幻灯片 3:
  - 标题: [自定义标题]
  - 内容: [自定义内容占位符]
  - 占位符: 2个
```

### 工作流程

```
框架PPT (demo_filled.pptx)
    ↓
解析框架结构 (提取3张幻灯片，6个占位符)
    ↓
LLM生成内容 (根据用户提示词)
    ↓
填充内容到占位符
    ↓
生成完整PPT (demo_filled-filled-*.pptx)
```

## 技术细节

### 使用的技术

- **PPTParser**: 解析框架PPT结构
- **LLMService**: 使用DeepSeek API生成内容
- **PPTFiller**: 填充内容到占位符

### 设计规范

- ✅ 保持16:9横版比例
- ✅ 应用Ant Design字体系统
- ✅ 保持原有布局结构
